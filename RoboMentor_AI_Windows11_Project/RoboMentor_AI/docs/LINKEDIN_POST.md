# LinkedIn project post

I’m excited to share **RoboMentor AI – an Offline-First Virtual Robotics Laboratory**, a software prototype I developed to make foundational robotics concepts easier for engineering students to explore.

The prototype includes:
- Interactive two-link robot-arm visualization
- Forward and inverse kinematics
- Elbow-up and elbow-down solutions
- Basic circular-obstacle path checking
- An offline robotics learning assistant
- Guided engineering experiments

**Tech stack:** Python, Streamlit, NumPy, Plotly and pytest.

My goal was to build a useful learning tool without requiring expensive physical robot hardware or paid APIs. This is an educational simulation prototype, and I’m continuing to improve its 3D modelling, path planning and validation.

I welcome constructive feedback from students, educators and robotics enthusiasts.
